# Employee Data Analysis – Microsoft Excel Exercise

## About the Project

This is my Module 4 Excel assignment. I used a small employee dataset with details like name, age, gender, job title, salary, start date and end date for 9 employees.

The aim was to practise common Excel functions and use them to answer simple questions about the employees.

## Tools Used

- Microsoft Excel

## What I Did

- Used MIN and MAX to find the lowest age, the highest salary and the employee who earns the most.
- Used IF to group employees as Young or Old by age, and as Low, Medium or High by salary.
- Used LEN to count the number of characters in each job title.
- Changed the start and end dates to one clear date format.
- Used TRIM to remove extra spaces from names.
- Used SUM and SUMIF to find the total salary of all staff and the total salary of staff that meet certain conditions.
- Used COUNT and COUNTIF to count the employees, those earning more than 50,000 and those who are salesmen.
- Used CONCATENATE to join first and last names into a full name.
- Used TEXT and IF to get the day and month from the end date and match each month to a season.

## Result

Each function is on its own sheet, so it is easy to see the original data next to the answers.

## What I Learned

This exercise helped me get more comfortable with Excel formulas. I learned how to clean text, work with dates, and use conditions to group, count and add up data.
